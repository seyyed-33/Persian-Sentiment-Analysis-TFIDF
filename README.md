# 🇮🇷 Persian Sentiment Analysis (TF-IDF)

This project uses **TF-IDF** and **Logistic Regression** to classify Persian comments as positive, neutral, or negative.

## 📊 Dataset
- **Persian Sentiment Dataset**
- ~34,200 comments
- 3 classes: positive, neutral, negative

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-Learn
- TF-IDF
- Logistic Regression

## 📈 Results
- **Accuracy:** 85.12%
- **F1-Score (macro avg):** 0.85
